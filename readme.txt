RajaSkin is a high-converting, luxury beauty, skincare, and cosmetics WooCommerce theme designed with an ultra-clean modern editorial aesthetic.

== Description ==

RajaSkin blends clinical clarity with high-end editorial aesthetics to deliver an exceptional e-commerce shopping experience. Built specifically for beauty, skincare, cosmetics, wellness, and self-care brands, RajaSkin offers:

* **100% Customizable Copywriting & Images**: Easily modify hero headlines, mission statements, features, category cards, editorial banners, and community galleries directly via the WordPress Customizer.
* **Instant Live Preview**: Enjoy sub-millisecond, real-time typing preview in the WordPress Customizer with zero page reload delay.
* **Aspect-Ratio & Size Preservation**: Uploaded images of any dimension or orientation automatically conform to strict design grids with responsive object-fit styling.
* **Bespoke Step-by-Step Checkout**: A streamlined, modern multi-step checkout workflow with persistent guest order tracking.
* **Refined Typography**: Pairs classic Playfair Display serif headlines with ultra-legible Inter body text for an unmistakable luxury feel.
* **Fully Responsive**: Flawless visual hierarchy across desktop, tablet, and mobile displays.

== Installation ==

1. In your WordPress admin dashboard, navigate to **Appearance > Themes**.
2. Click **Add New** and upload `rajaskin-theme.zip`.
3. Click **Install Now**, then **Activate**.
4. Install and activate **WooCommerce** for full e-commerce capabilities.
5. Go to **Appearance > Customize > RajaSkin Theme Settings** to personalize your branding, copywriting, and imagery with real-time live preview.
